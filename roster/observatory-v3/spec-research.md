1. **Observed identity versus clock estimate:** accepted intake forbids clock-manufactured anchor or camera movement, specifically successor observed r0 versus clock r6→7 (`briefs/observatory-v3-intake.md:13`, `:82`). Current production fallback round is schedule-derived (`src/main.ts:179`–`:181`) and observation retention is age/schedule-sensitive (`:136`–`:151`). Static study proves only representational separation.
2. **Next observed round versus next clock opportunity:** intake names conditional selected N/R+1 above (`briefs/observatory-v3-intake.md:13`); existing high-round browser scenario expects estimated r6→future r7 despite selected observed r0 (`tests/e2e/dashboard.spec.ts:235`–`:241`). The study keeps the original r1 node and marks elapsed (`roster/observatory-v3/studies.html:30`, `:37`). These are distinct contexts in existing evidence.
3. **Solid observation versus ancestry/finality:** intake requires verified solid relationships and explicit gaps (`briefs/observatory-v3-intake.md:78`); study uses a dotted predecessor relationship where proposal hash is absent (`roster/observatory-v3/studies.html:30`). Observation styling alone supplies neither ancestry nor finality.
4. **Inspection versus collection pause:** accepted frozen pin/follow/newer-items/eviction behavior (`briefs/observatory-v3-intake.md:53`) is not implemented by the read dashboard pause control, automatic group selection or five-summary history (`src/dashboardView.ts:163`, `src/main.ts:194`, `:310`).
5. **Optional doctrine versus resolved scope:** broader V3 doctrine says receipt timelines/watched filters/celebration are conditional (`kb/context/v3-contract.md:14`); validated intake excludes them explicitly (`briefs/observatory-v3-intake.md:21`, `:78`).
6. **Study acceptance versus release acceptance:** the 32 stored render checks and root-selected refined screenshots are intake/design direction only (`briefs/observatory-v3-intake.md:84`–`:86`). No 768/1920/2560/5120 records, dense 150-instance interaction, real candidate switching, motion/pin/cancellation or independent production visual acceptance exist in that metadata.
7. **Historical risk notes versus current facts:** historical payload attribution anchors have been partly superseded by the current payload comparison, while the equal-round proposal rejection remains in the source read (`kb/risks.md:13`–`:14`, `src/dashboardView.ts:224`, `src/monitor/networkMonitor.ts:335`).
